# loops

Track **open questions** you're actively thinking through as durable, authored markdown
notes with a lifecycle — distinct from the settled answers filed in your knowledge base.

A **loop** = a question + why it matters. You log typed, authored entries
(`note` / `next step` / `tried` / `blocked by`) over time, then **close** it by graduating
the answer into your taxonomy. Loops live in a single global `loops/` directory; topic is a
frontmatter `area` tag, not a folder.

## Skill

- **`loops`** — how to create and use loops. Triggers on "open a loop", "new loop",
  "add to the loop", "close this loop", or questions about the loops methodology.

## Install

```bash
claude plugin marketplace add https://github.com/jordangaston/claude-plugins
claude plugin install loops@jags-plugins
```
